# REL-05 — Store Listing Technical Assets & Submission

**Workstream:** Release | **Phase:** 4 | **Size:** S | **Depends on:** REL-01, SEC-06 | **Source:** §5 Phase 4 (app store media assets)
**Status:** todo
**Skills:** vv-task-workflow, vv-ci-release, vv-privacy-security, vv-licensing-iap

## Goal
Engineering side of store submission (marketing copy is out of scope).

## Scope
- [ ] Automated screenshot generation (integration_test + fastlane snapshot/screengrab) for all required device sizes.
- [ ] App icons, launch screens, feature graphic per flavor.
- [ ] Store metadata in repo (fastlane `metadata/`), IAP product configuration in both consoles.
- [ ] Reviewer notes: demo instructions, offline model explanation, background-mode justification, and an explicit statement that the app does not record phone/VoIP calls and only records after a user tap with a visible indicator.

## Acceptance Criteria
- App submitted and approved on both stores.
