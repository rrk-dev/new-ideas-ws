# Device verification — APP-02 Recording Library & Local Full-Text Search

Host tests cover the FTS5 index, its triggers and query building
(`app/test/db/search_index_test.dart`, incl. `[APP-02/AC1]`: 1,000 recordings × 20 transcript
segments + extraction, every query < 200 ms on the CI host), the v1 → v2 migration with backfill
(`app/test/db/migrations/vaultvoice/migration_test.dart`), deletion of rows/files/search entries and
of the exported note on request (`app/test/db/recording_deletion_test.dart`, `[APP-02/AC2]`) and
the Library / detail / action-item screens (`app/test/widget/library_screen_test.dart`). These rows
confirm the timing on real (slower, encrypted-DB) phones and the deletion of an exported note
through the real SAF / security-scoped-bookmark writers, which could not be run when this was
authored (no devices, no Xcode / Android SDK).

Seeding: dev flavor, a debug build with the test seeding hook or 1,000 imported short clips;
alternatively copy a DB generated by the host test (same schema) into the app container.
