# REL-03 app size — host measurements (2026-10-14)

Environment: macOS 27 arm64 (Apple M3 Pro), Apple clang (Command Line Tools), CMake 4.4.4,
Ninja 1.13.2; `native/build.sh host` at whisper.cpp v1.9.5 (`d1be6fd`) + llama.cpp `d812350`.
Mobile store sizes need signed release builds (Xcode / Android SDK are not installed here) —
rows in `docs/test-plans/device/REL-03.md` (⏳, CI release workflow).

## Native bridge (host, Metal + Accelerate, Release)
| Artifact | Bytes | MiB | Note |
|---|---|---|---|
| `libvv_native.dylib` (unstripped) | 10 280 272 | 9.80 | whisper + llama + one ggml |
| same, `strip -x` | 9 357 864 | 8.92 | baseline `host_native_lib_darwin_mb` in `tools/ci/size-budget.json` |
| same, stripped + `gzip -9` | 2 699 372 | 2.57 | ≈ what a store download adds (stores ship compressed) |

`size -m` breakdown of the unstripped dylib:

| Segment / section | Bytes | Share |
|---|---|---|
| `__TEXT,__text` (code) | 3 387 544 | 33 % |
| `__TEXT,__cstring` + `__const` | 392 177 | 4 % |
| **`__DATA,__ggml_metallib`** (embedded Metal library, `GGML_METAL_EMBED_LIBRARY=ON`) | **5 192 670** | **51 %** |
| `__LINKEDIT` (symbols, exports) | 1 048 576 | 10 % |

**Metal library verification:** the embedded Metal library is the largest single part of the
binary (5.0 MiB of 9.8 MiB) but compresses well (the whole stripped library gzips to 2.6 MiB),
so its download cost is ≈ 1–1.5 MiB. iOS uses the same embed (`native/build.sh ios`). Options if
the budget gets tight: ship a precompiled `default.metallib` for the iOS GPU family instead of the
embedded source (`GGML_METAL_EMBED_LIBRARY=OFF` + bundle resource) — not needed at today's sizes.

## Build settings that keep the binary small
| Platform | Setting | Where |
|---|---|---|
| Android | arm64-v8a only (Flutter's default ABI list replaced) | `app/android/app/build.gradle.kts` `ndk.abiFilters` |
| Android | App Bundle (`flutter build appbundle --target-platform android-arm64`) → per-device split APKs | `tools/release/build_release.sh` |
| Android | R8 code shrinking + resource shrinking (`isMinifyEnabled`, `isShrinkResources`) | `build.gradle.kts` release |
| Android | native `.so` stripped by AGP in release; `libvv_native.so` also `llvm-strip --strip-unneeded`, 16 KB aligned | AGP default, `native/build.sh android` |
| Android/iOS | Dart AOT `--obfuscate --split-debug-info` (symbols kept privately) | `tools/release/build_release.sh` (REL-01) |
| iOS | `DEAD_CODE_STRIPPING`, `STRIP_INSTALLED_PRODUCT`, `STRIP_STYLE = all`, dSYM kept privately; bitcode off (n/a since Xcode 14) | `Runner.xcodeproj` Release/Profile |
| iOS | `vv_native.framework` stripped at build (`DEPLOYMENT_POSTPROCESSING`, `STRIP_STYLE = non-global`) + dSYM | `native/build.sh ios` |
| Native | hidden visibility, `-dead_strip` / `--gc-sections`, export list | `native/CMakeLists.txt` (FND-06) |
| All | **zero model weights in the binary** — models download post-install (MDL-01/02); only a VAD model ≤ 5 MiB could ship | `tools/ci/size_check.py` scans artifacts + `app/assets` |

## Budget
`tools/ci/size-budget.json`: 40 MiB store download per platform (PRODUCT-DECISION), iOS install
≤ 120 MiB, host bridge ≤ 15 MiB; > 10 % growth over a recorded baseline fails
(`tools/ci/size_check.sh`). Mobile baselines are recorded by the first release-workflow run
(`--update-baseline`).
